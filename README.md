# 📝 WenNote - 你的极简离线笔记本

一个纯粹、极简、完全离线的单文件 HTML 应用。支持本地存储（localStorage），无需联网，数据完全属于你自己。

## ✨ 核心特性

- 💰 **极简记账**：支持自定义分类与图标、图片上传、大图折叠展开、月历日历筛选。
- ⏳ **倒数日 / 纪念日**：大卡片设计，支持上传自定义背景，自动计算剩余天数。
- 🔢 **次数记录器**：精美的环形进度条设计，支持向上翻页数字动效。
- 📋 **备忘录**：支持待办清单，勾选完成后自动划线并归档。
- 🎨 **双主题切换**：提供「奶油卡片风」和「液态玻璃风」，支持自定义主题色与全局壁纸。
- 📱 **PWA 支持**：支持添加到手机桌面，像原生 App 一样全屏运行，并支持自定义 App 图标。

## 📱 如何添加到手机桌面 (PWA)

1. **iPhone (iOS)**：使用 Safari 浏览器打开上方网址 -> 点击底部「分享」按钮 -> 向下滑动选择「添加到主屏幕」。
2. **Android (安卓)**：使用 Chrome 或 Edge 浏览器打开网址 -> 点击右上角「三个点」 -> 选择「添加到主屏幕」或「安装应用」。

## 🛠️ 技术栈

- **HTML5 + CSS3 + Vanilla JavaScript**
- 纯单文件架构（所有功能均打包在 `WenNote.html` 中）。
- 无后端、无数据库，数据全部存储在浏览器的 `localStorage` 中，保证绝对的隐私安全。
